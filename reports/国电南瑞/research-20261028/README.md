# 国电南瑞研究复核包

对应[研究报告](../国电南瑞研究报告-20261028.md)，财务截止2026年9月30日，研究与行情截止2026年10月28日晚。

- inputs.json、calculate.py、results.json：公开原始数值、估值假设及Decimal复算。
- financial-rigor.txt：市值、关键财务双渠道核对与三年情景记录。
- terminal-audit.txt、terminal-flip-*.txt：人民币终值约束与折现率翻转检查。
- source-manifest.json：三份原PDF链接、哈希和本地缓存路径。
- audit.py、audit-results.json、audit-verdict.txt：固定种子20261028；有效金融数据181项，随机28项加定向21项，共49项核验通过；非财务日期及编号排除均留痕。
- test_calculation.py：8项测试，覆盖市值、TTM、单季、分红跨期、现金桥、金融资产去重、IRR及终值时点。

calculate.py及测试使用Python标准库和仓库工具，无需网络。audit.py还会检查原件转录，依赖source-manifest.json对应的三份公开PDF提取文本，位置为tmp/pdfs/nari-20261028/nari-{q3,h1,2025}.txt；这些原件缓存不随报告提交。新检出环境应从清单原URL重新下载并提取后再运行完整审计，不能把缺原件时的检查跳过后宣称相同覆盖。

三年退出PE是显式情景假设；十年终值仅用永续公式。工具近似IRR使用第十年利润和固定初始股息收益率，严格模型使用第十一年利润和逐年股息，两列不能混用。6%敏感性档包含分母过窄的情景，不能作为全部约束合格的买入依据。

镜像只算同一底层来源，部分附注仍缺独立第二来源；假设一致性与公式通过不代表未来收益已验证。十年压力测试只约束集中度，不单独决定买卖。
