## 离线复算

- `inputs.json`：原始金额以人民币元为单位，明确更正口径、股数及情景输入。
- `vendor-snapshot.json` / `cross-source.json`：最小供应商字段与28项对照，不依赖实时网络。
- `calculate.py` / `calculations.json`：Decimal季度差分、TTM、现金与票据观察、五年逐年分红及退出PE模型。
- `financial-rigor.txt`：共享金融验算工具输出；ANSI及行尾空白已清理。
- `source-manifest.json`：S1—S10实际来源、日期、原件或提取文字哈希；S7完整IR提取文本不是原PDF字节哈希。
- `audit.py`及`audit-*.json` / `audit-verdict.txt`：抽样总体、排除理由、未舍入源值、显示精度及来源与判决。
- `test_calculation.py`：独立数学与来源约束测试。

从本目录运行，Python标准库即可：

```powershell
python calculate.py
python audit.py
python test_calculation.py
```

原始PDF、网页长文本、IR提取文字及旧报告逐项复核稿仅保留在被Git忽略的本机`local/五粮液-20261105/`。重新取得原始缓存后的来源清单刷新使用`calculate.py --refresh-manifest`；普通离线复算不需要该选项。
