## 财务口径

2021/2022利润采用2023年报按解释16号重述值。2021归母门户仍用初报、扣非却已更新，差异不因低于1%而消失。2024年报历史资产比较列异常，不用于本系列历史资产输入；2021每10股送4股及加权EPS口径单独标注。

2021与2025产品按品牌、2022—2024按价格类别，不能直连为单品高端化曲线；价位门槛每升130元不是终端高端酒定义。产销存以千升列示，不直接与项目原酒吨产能相加。经销商产品×地区合计不保证去重户数。

酒类主营收入、集团营业收入、消费者实际动销各自不同。省内单Q3增长14.44%与九个月下降4.23%可以并存；省外单Q3下降29.67%。单季为同口径累计差分，不是独立披露的终端销售测量。

简化现金余量=CFO减购建长期资产付现，不是严格FCFE。其他流动资产未完全拆分定存和质押；现金等价物扣租赁及到期非流动义务约46.33亿元不是完整净现金，也不是可全部分配现金。Q3新租赁支付、对象、期限等缺口保留。

## 同一利润路径，两种终值分配情景

盈利起点为扣非TTM91.7883亿元。扣非仍可能含正常资金收益，不等同于纯卖酒利润；股息规划基数是年度归母净利润，将65%用于模型扣非盈利只是研究近似，不是计算实际法定股利方案。

十年内盈利年变化-5%/+2%/+6%，每年模型股利65%，均为显式情景，2028以后比例不是已批准政策。股数保持当前数是假设，不另加回购或稀释收益。未来模型年度年末分配不对应真实除息日期，不称XIRR，不计个人税费或股息再投资。

潜在分配能力终值：新增留存资本回报代理取20%，长期g=0%/1%/2%，由1-g/R得到100%/95%/90%潜在可分配比例；使用第十一年盈利及前向倍数，终值在第十年末。20%不是实测ROIC，更不是充分核验租赁/维护投入后的FCFE转换率。这一情景不是价值绝对上限。

持续65%股利终值：同一盈利路径和g下，仅对持续65%股利折现，并单独计算含息IRR。没有将留存资金判为无价值，而是没有在现有股利流之外预先假定提高分配或释放资产。未来若资本配置和分配政策改变，需重新计值。两种终值不能相加或平均。

两种整体权益模型都不再额外加现金、定存、票据、存货或已并表子公司，也不把已于2026年7月支付的6.56元加进未来现金。若以后改为经营/财务资产分部估值，必须同步移除相关收益和统一债务处理。

r=8%是人民币研究门槛，非实测资本成本；r=10%超出项目标准CNY区间，仅供参考。r-g小于5个百分点的组合单独标注。工具rf1.7%是历史兼容参数，不是当前国债收益率。重大监管与品牌冲击未充分建模。

terminal_value.flip以无分红的终值近似运算。接口重复同一个条件情景，不赋予不同情景主观概率；其输出仅核对终值敏感性，不能代替正文实际逐年股利IRR与门槛翻转。
