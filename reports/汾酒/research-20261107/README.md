## 文件与离线复算

- `inputs.json`：原始人民币元数据、股数、分红、定存与质押、项目和情景假设。
- `vendor-snapshot.json` / `cross-source.json`：独立供应商最小字段及28项对照。
- `operating-inputs.json`：S9产品、渠道、区域及经销商原值；三个收入维度重叠，不能相加。
- `calculate.py` / `calculations.json`：Decimal季度、TTM、现金/义务分层与五年逐年股息及退出PE模型。
- `financial-rigor.txt`：共享验算工具输出，无ANSI颜色与行尾空白。
- `source-manifest.json`：实取来源、哈希、视觉核验范围及缺口。
- `audit.py`、`audit-*.json`、`audit-verdict.txt`：总体、排除、补充、固定样本、未舍入源值和判决。
- `test_calculation.py`：独立复算约束。

从本目录运行，Python标准库即可：

```powershell
python calculate.py
python audit.py
python test_calculation.py
```

## 方法边界

模型以扣非TTM为基数，假设五年盈利增速分别-5%/+2%/+6%、退出PE12/16/20、每年65%派息；2028年以后的派息比例是研究假设，不是已获批准的续期规划。按逐年末现金流求IRR，不将股价年化涨幅与历史股息率机械相加；不另外叠加净现金、定存、存货或已付6.56元股息。

其他流动资产未取得Q3详细构成及受限拆分，不全当现金；其他筹资付现不全当租赁。前三季FCF对本年已付上年度股利覆盖91.36%，期间不同，不据此单独判全年不可持续。11月6日说明会日程已过但问答未取得，不能称为未来催化剂或虚构回复。
