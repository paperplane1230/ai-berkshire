## 文件

- `inputs.json`：以元为单位的原始财务抄录、模型假设。
- `calculate.py` / `calculations.json`：Decimal精确差分、TTM、估值、逐年股息及退出现金流。
- `cross_checks.json` / `financial-rigor.txt`：69项双渠道对照及共享财务验算工具输出。
- `source-gaps.json`：2025年9月末应收和存货只取得东方财富，未作独立原件复核；不计入69项通过数。
- `source-manifest.json`：实际获取URL、响应哈希及PDF视觉核验页码。原始大文件在被Git忽略的本地资料目录。
- `audit.py`、`audit-universe.json`、`audit-exclusions.json`、`audit-results.json`、`audit-summary.json`、`audit-verdict.txt`：抽样总体、事先排除原因、逐项来源与判决。
- `test_research.py`：独立算式、现金流残差与哈希测试。

离线复算（从本目录运行，Python 3标准库即可）：

```powershell
python calculate.py
python audit.py
python test_research.py
```

`verify_sources.py`用于重新从本地已下载供应商响应生成对照表，需要仓库`local/伊利股份-20261029`缓存，不会自动联网。原始DOCX问答仅结构化提取文字，未做版式核验；不依赖其排版提取财务数字。

## 估值边界

五年退出PE模型不是永续增长DCF；分红在每年末支付、末年出售，采用现金流IRR。没有把历史已除息股息计入未来现金，没有额外叠加留存利润、回购收益或未经核验的净现金。10%折现为研究回报门槛，不是监管或公司承诺。
