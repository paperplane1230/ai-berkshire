## 复算

运行本目录的 Python 脚本 [估值复算.py](估值复算.py)，仅需标准库和仓库内的 financial_rigor、terminal_value。它以[冻结输入](输入.json)重建[输出](复算输出.json)及两个工具日志。[财务对照](财务对照.json)有65条财报项目与东财取数，全部按原始精度一致，已含历史年度复核，不与五年30项另行相加。2021、2022归母及扣非沿用2023年报追溯后的比较列，品类收入毛利主要是发行人单源。不能用“65项一致”去背书终端库存或未来预测。

三年情景依次输入前三年每股扣非增长、三年退出倍数；十年另取十年增长及之后永续增速；计算时不把三种情景按概率平均。两种模型从2027所属财年起逐年计算普通分配，退出价理解为当期模型股息发放后。65%取**模型扣非盈利**为分母，不是公司派息承诺；首个现金流按距报价日约一年处理，不是对实际登记、支付日的预测。TTM盈利含存款利息，不额外释放账上资金。另列可能属于买家的中期0.20元，但它不是2026所属年度所有可能剩余分配的上限。资产加总法相反：先除去假设税后的存款收益，再对可动用余额计价，分出的股息不作为剩余本金第二次相加。

[独立反算](事实反算.py)用另一套循环/牛顿法或割线法检验现金流求根；[自动测试](test_series.py)与之交叉。终值工具的近似资本增值率加固定股息率，与文中逐年含息IRR不是同一指标；工具内1.7%仅为历史规则参考，不是11月26日国债收益率。二期测试4000万元为无期限、本金现在一次投入、次年起年末均匀收款；15年无残值改用年金。两者不代表项目方可研结果。

## 五年分位的口径

数据区间为2021-11-26至2026-11-26，含首尾1,212个不同的交易日，取当时市值与滚动归母盈利对应的正PE_TTM，而非静态PE_LAR。418个日值不高于末日，故经验百分位34.49%。升序以位置 $(n-1)q$ 线性插值得到四分位数。三季报公布前后10月27日、28日的历史倍数分别与当时可得的半年版、三季版滚动归母勾稽。不是用目前股本乘以历史复权股价，也不是含股息总回报。日度数据来自单一供应商当日回溯，不能保证从未经修订。[统计与取数指纹](估值历史与横比.json)及[原始接口](来源索引.json)留有截止日；序列指纹以日期、收盘价（四位）、股数（整数）、市值（两位）、滚动PE（八位）用竖线连接，日期升序，UTF-8、LF、无末尾换行。同日横比仅说明估值差异，不能代替公司自身的现金流估值。
