## 复算文件

- `inputs.json`：原始财报抄录，单位人民币元；包含明确的摘要精度说明。
- `vendor-snapshot.json`：独立采集渠道的最小关键字段、行情及URL/哈希。
- `calculate.py` / `results.json`：精确十进制计算，五年逐年分红及退出PE模型。
- `cross-source.json` / `financial-rigor.txt`：跨来源差异明细及共享校验工具输出。
- `audit.py`、`audit-universe.json`、`audit-exclusions.json`、`audit-sample.json`、`audit-checks.json`、`audit-summary.json`、`audit-verdict.txt`：总体、排除理由、固定样本和结果。
- `source-hashes.json`：公开原文及PDF的获取时间、URL、哈希和视觉核验范围。
- `test_calculation.py`：独立复算约束。

从本目录离线运行，Python标准库即可：

```powershell
python calculate.py
python audit.py
python test_calculation.py
```

复算不依赖被忽略的local目录。原始长文本、PDF及渲染图仅在本机local/同仁堂-20261030及local/三季报-20261030/tongrentang中保留，不复制到公开仓库。
