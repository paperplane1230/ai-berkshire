## 可复算文件

- `inputs.json`：以元为单位的发行人原值、A/S股本、历史分红与显式模型假设。
- `vendor-snapshot.json`：最小化东方财富28项取数、两路原始行情及响应哈希，不依赖外部网络即可复核。
- `calculate.py` / `calculations.json`：Decimal单季拆分、TTM、估值、有限五年股息及退出价值IRR。
- `financial-rigor.txt`：共享金融验算工具输出，已剥离终端颜色并清除行末空格。
- `audit.py`、`audit-universe.json`、`audit-excluded.json`、`audit-sample.json`、`audit-checks.json`、`audit-directed.json`、`audit-summary.json`、`audit-verdict.txt`：固定总体、抽样、来源与判决。
- `test_calculation.py`：独立约束测试。
- `source-manifest.json`：实际获取URL、时间与原始响应哈希；`capture_snapshot.py`可从本机来源缓存重新生成快照，但日常复算不依赖它。

从本目录离线复算：

```powershell
python calculate.py
python audit.py
python test_calculation.py
```

## 关键口径与缺口

2024商业板块出表与2024/2025史克股权处置造成跨年断点；2026现金流受银行承兑贴现节奏影响；过去两期4.79元分配不能永久化；模型不重复叠加已派息资金、净现金或联营投资价值。

S股同日可靠价格/汇率、三季度存单及应付费用详细附注、真实终端库存、完整问答、发布前一致预期均未充分取得，因此不输出S股建议、伪精确净现金或市场预期差结论。
