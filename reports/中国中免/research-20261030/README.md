抽样总体是工具识别并补充的表格数据，不是所有正文数字的穷尽清单；正文重要数字另作定向核查。单源附注与模型假设均明确标记，模型参数通过只意味着表述和算术一致，不表示未来预测通过。数值按报告显示精度比较，未舍入源值同时保存，避免小金额正常舍入被误判为来源冲突。

## 文件及复算

- `inputs.json`：原始财务抄录、A/H股数、报价和显式情景假设。
- `cross-source.json`：28项独立采集渠道的精确对照；不依赖本机原始网页缓存。
- `calculate.py` / `calculations.json`：Decimal季度差分、TTM、租赁现金边界、分市场市值及五年逐年股息IRR。
- `financial-rigor.txt`：共享财务验算工具输出，已去除ANSI颜色和行尾空白。
- `source-manifest.json`：实际获取时间、公开来源URL、原响应哈希和PDF页数；不发布整篇第三方原文。
- `audit.py`及`audit-*.json` / `audit-verdict.txt`：抽样总体、事先排除、原值、显示精度、逐项来源及判决。
- `test_calculation.py`：独立约束测试。

从本目录离线运行，Python 3标准库即可：

```powershell
python calculate.py
python audit.py
python test_calculation.py
```

## 关键限制

原始PDF、网页长文本及图像留在被Git忽略的本机 `local/三季报-20261030/cdf/`。产品、子公司、租赁和部分资产细项主要依赖发行人单源；外汇为单源当晚快照。没有把其他筹资现金全额当租赁付款，也没有把全部货币资金视为母公司股东可自由分配净现金。

估值统一使用中国会计准则，A/H分市场报价；H股国际准则利润未与A股混算。五年模型不额外叠加净现金或历史已除息股息，不预设A/H折价收敛；H股税费与实际派息换算另有条件。
