## 文件与复算

- `inputs.json`：原始金额以人民币元为单位，包含政策和恢复路径假设。
- `vendor-snapshot.json` / `cross-source.json`：最小供应商快照及28项对照，无需实时网络。
- `calculate.py` / `calculations.json`：Decimal季度、TTM、财务资产分层、恢复模型和资产反向敏感性。
- `financial-rigor.txt`：项目共享验算工具输出，已去ANSI及行尾空格。
- `source-manifest.json`：实际取得URL、原始响应与本地文件哈希；正文来源编号对齐，视觉核验图片指向本机local目录。
- `audit.py`和`audit-*.json` / `audit-verdict.txt`：总体、事先排除原因、样本、原值、显示精度及判决。
- `test_calculation.py`：独立计算约束。

从本目录离线运行：

```powershell
python calculate.py
python audit.py
python test_calculation.py
```

普通复算不依赖被忽略的原始文件。只有重新盘点本机来源时才运行`calculate.py --refresh-manifest`。原PDF、完整公告、图像及旧报告对照稿保存在`local/洋河股份-20261106/`，不公开复制。

## 估值边界

微利TTM不用于机械复利。第一套模型给出五年明确盈利恢复路径，退出倍数为包括财务资产在内的整体股权倍数，不再加现金。首个模型年100%派息仅近似现有规划尾段，后四年80%为假设，未预测具体派付日期。

第二套模型反推当前价格所要求的经营盈利，财务资产A是情景值而非已验证净现金；必须排除A对应资金收益，不叠加存货。两模型不能相加，180亿元不是全部金融资产价值上限。约31.20元及24.96元仅为特定资产、经营盈利、倍数和折价条件下的演示，并非确定内在价值或股价底。
