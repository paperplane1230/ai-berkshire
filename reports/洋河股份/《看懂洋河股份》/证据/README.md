## 统一口径

- 当前价37.24元；发行股本1,506,445,074股。市值按当前价乘全部发行股数；流通股不是总股本。
- 2021和2022归母、扣非采用2023年报按解释16号重述值。东方财富2021归母仍列初报值，差58,801.63元；保留这一差异，不因小于1%就称精确相等。
- 财报与东方财富属于两条公开取数渠道，不是两次独立审计。产品、地区、库存吨数、资本与部分附注仍主要来自发行人，单源边界不因抽检通过而消失。
- 年度酒类产品/地区/渠道收入不等于全部集团收入，且三个维度重叠；中高档酒是公司以出厂价至少100元/500ml划分的类别，不等于全部高端白酒或梦之蓝。
- 简化自由现金流仅为合并经营净现金减购建长期资产现金支出，不是严格归母自由现金流，不意味着可全额分红。
- 公司库存、经销商库存、终端库存与消费者开瓶分开；合同负债中的真实预收与未结折扣分开；股息归属年度与支付年度分开。

## 两类模型不要混在一起

整体权益模型中的利润包含金融收益，末期倍数也是全部权益倍数，因此没有额外加现金、金融投资或存货。它用于观察不同盈利恢复与估值条件的压力，不是清算价格；低利润、低倍数可能隐含资产长期折价或消耗。

经营DCF模型先假设剔除单列金融资产收益、加回税后借款利息的经营盈利，再按假设现金转换率估算经营自由现金流近似值；净财务资产A单列为现值，已包括债务、经营准备金、受限与回收折价等调整。不再减同一笔债务，不再加存货、已并表子公司价值，不再保留A对应收益。A=100/150/180亿元和现金转换率70%/80%/85%均为研究情景，不是发行人指引或已核实可分配现金。亏损年份按全部亏损额流出，不用小于100%的转换率减轻现金损失；实际仍可能需要额外资本，不能称为损失上限。

折现要求r=8%是人民币研究门槛，不是声称精确估出了WACC；由于借款规模相对权益较小，经营资产折现采用低杠杆近似，仍有方法风险。稳态增量资本回报率15%是判断，不是当前ROIC。正式文章不以这组假设包装单一公允价值。

终值使用第十一年盈利，前向倍数为(1-g/ROIC)/(r-g)。年度现金转换率与稳态留存率各自披露，终值年之后的资本需求不能当作已验证事实。6%下较强情景的分母不足5个百分点，只作参考；10%超出本项目人民币标准区间。重大监管变化未充分建模。

显式期70%/80%/85%的转换率在上述终值公式中变为100%/93.33%/86.67%，属于重要假设变化。结果另保留“转换率不改善”压力档：固定g而使用原现金转换率折现终值，代表持续现金折损或较低新增资本回报，并非与15%增量回报同时成立的第二个基准。终值权重较高，正文应同时呈现这一敏感性。

整体权益IRR用逐年年末分红与末年除息后价格求解；未来第一完整模型年并非未披露Q4。第一模型年100%分红、以后80%是研究假设，不表示2027年之后政策续期。不计税费、再投资和真实派息日差异，不称XIRR。

共享terminal_value.flip采用无分红的终值近似。为避免赋予主观情景概率，接口中重复输入同一个条件情景，不把不同情景混为加权期望。其结果仅留作终值敏感性核对；正文的含息IRR来自实际逐年现金流，不能拿工具近似替代。

数字与公式通过不等于投资判断被证明。真实渠道库存、连续批价、资产可分配性、未来维护投入和改革效果仍有证据缺口。
