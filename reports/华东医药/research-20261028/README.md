# 华东医药研究复核包

截止日2026-10-28晚；金额底稿以人民币元为默认单位，报告表格标示亿元。仅公开资料，不读取私人持仓。

## 文件

- `inputs.json`：原件数值、双渠道刊发对照、明确声明的情景假设。
- `calculate.py`：调用`financial_rigor.exact`执行Decimal计算、TTM与季度拆分、完整OCF变化桥、研发资本化与商誉敏感性、三年及十年模型。
- `results.json`：计算产生的全部派生数。
- `financial-rigor.txt`：市值、估值、交叉验证与三年工具记录。
- `terminal-audit.txt`、`terminal-flip-*.txt`：币种、永续增长、折现率及风险归属检查。
- `test_calculation.py`：独立不变量/恒等式测试，包含Q3现金转负和第11年利润退出口径。
- `audit.py`、`audit-results.json`、`audit-verdict.txt`：先冻结有效总体，再以固定随机种子20261028抽取向上取整15%的有效金融数据；本地采样不使用公共工具的30项上限。披露事实、复算与假设核对分开，不以输入假设一致等同外部事实验证。
- `source-register.md`：原件链接、独立刊发媒体、口径矛盾及原件页码。
- `render_check.py`：从已下载原PDF生成指定页PNG供视觉核验，需PyMuPDF；输出保存在tmp/pdfs/huadong-20261028。

## 模型纪律

1. TTM=2025全年+2026前三季-2025前三季，不用Q3累计乘4/3。
2. 三年模型以扣非TTM为起点，不把全部在研产品盈利加到当前利润。
3. 十年每年分红明确建模，用现金流求根；第十年退出价值使用第十一年利润乘前瞻PE。共享工具的近似锚点使用第十年利润乘退出PE及股息近似，不替代严格现金流IRR。稳态利润须扣除支持g/ROIC的再投资，剩余部分才可分配，不代表现有现金及期末金融资产全部单列兑现。
4. 当前净现金不另加到盈利估值，避免未经剔除金融收益与营运需求便重复计价。
5. r=8%是CNY长期资本成本假设；rf输入是工具参考假设，不声称实测当天国债利率。工具内置市场基准可能较旧。
6. 三年判断定价，十年约束仓位；r±2pp结果若翻转，显式降级仓位，不单独否决买入。
7. 样本全部按照来源/公式逐项核对，假设、四舍五入、解析器误抓数字单独标记。

## 数据限制
